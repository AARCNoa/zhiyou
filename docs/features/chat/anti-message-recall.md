# 防撤回

**聊天** · 可开关 · 可点击 — 拦截对方与自己撤回的消息：原消息留在聊天里，并按所选样式给出提示。

## 展示样式（二选一）

| 样式 | 表现 |
| --- | --- |
| 徽标（默认） | 原消息保持可见但整体半透明，气泡旁显示一枚徽标；徽标可选文本或图标 |
| 旧版 | 在原位置插入一条系统提示，内容与时间格式都可自定义；打开后徽标样式自动停用 |

## 设置项

| 设置项 | 说明 |
| --- | --- |
| 防撤回自己 | 自己撤回的消息同样保留 |
| 徽标类型 | 用文本还是图标作为徽标 |
| 迁移旧版提示 | 把历史上由旧版样式插入的系统提示批量改成当前样式 |
| 旧版样式 | 切换到「插入系统提示」的展示方式 |
| 旧版提示内容 | 旧版系统提示的文案 |
| 时间格式 | 旧版系统提示里的时间格式 |

## 说明

- 撤回的消息只在本地保留，不会重新发给任何人；迁移只改本地展示，不动服务器上的任何数据。
- 迁移只处理最近一段系统提示记录，过程中显示进度，可随时退出；迁移后这些记录按当前样式重新显示。
- 与「朋友圈防撤回」「朋友圈评论防撤回」相互独立。
