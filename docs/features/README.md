# 功能索引

> **239 个功能 / 15 个分类**（微信 8.0.80）。当前版本可见 238 个：一项随微信版本自动隐藏，
> 见「系统与隐私 / 禁用『转发截图』提示」。
> 「隐藏联系人」在「联系人与群组」与「密友功能」各出现一次，是同一个开关（后者是该分类的总入口）。
> 46 个内部服务单列在文末，不建卡、无开关。
> 名称后标「可点击」= 有二级配置页；带链接的 = 有单独说明页（其余功能这一行说明即全部行为）。
> AI 能力（好友档案、智能建议、自动回复、朋友圈帮我评论、总览、群聊摘要）在设置页「AI」里配置，
> 不在本清单内。
