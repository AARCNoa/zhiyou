# 总览（今日总结 · 好友事件 · 群摘要）

**AI** · 群摘要部分可开关 — 首页标题栏便签图标（搜索图标左侧，带未读角标）打开的三块内容。

## 三块内容

| 分区 | 里面是什么 |
| --- | --- |
| 今日总结 | 最上方一行，点开是今天记下的约定、群摘要与工作群任务 |
| 好友 | 所有建过档案的好友；开了自动回复的，副标题是最近一条重要事件 |
| 群聊 | 群摘要卡片与历史；工作群在群名后显示当前任务与进度 |

- 没开自动回复的好友收进「未开启自动回复」折叠组，默认收起，点向下箭头才显示。
- 「好友」「群聊」两个标题整行可点，右侧箭头切换显示（向下展开、向上收起）；收起只影响列表，不影响数据。
- 有未读时显示红色角标：入口上的数字是全部未读之和（群 + 好友），列表里每个好友、每个群的角标是自己的未读数，压在头像左上角。
- 点右侧空白处或向左滑关闭面板。

## 今日总结

- 默认收起，只占一行标题；点标题行或向下箭头看内容。
- 当天第一次整理会自动展开一次，之后每次打开都是收起的。
- 今天有记录才显示内容；一条也没有时写「今天还没有记录」。
- 记录有增减才重新生成，右侧「整理」可手动重算一次（会当场展开）。
- 未配置 AI 接口时显示本地拼装：几位好友、几条约定、几个群、最近几条标题。
- 换天后从空开始，旧的一天不保留。

## 好友的重要事件从哪来

自动回复开启后，聊天里出现下面几类内容就记一条：

| 类型 | 例子 |
| --- | --- |
| 对方提出见面、出去玩、一起做什么 | 「我们明天见一面吧」——还没定下来也记 |
| 对方告知的重要情况 | 怀孕、生病受伤、家里出事、工作变动、要离开或要来找你 |
| 你答应下来的事 | 「周六帮你搬东西」「明天给你答复」 |

日常闲聊、撒娇、报备吃什么不记；同一件事只记一次。

## 怎么看

1. 打开总览，点好友。
2. 事件按 1、2、3 编号，最新在上，每条带记录时间和细节。
3. 进入即清红点。**看过不等于删除**：它仍然知道这些事记过，对方再提不会重复记录。

## 清空

好友详情页顶部「共 N 条 · 清空」，二次确认后清掉这位好友的全部提醒。

- 只有手动点才清空，不会自动清理；
- 清空后它不再知道这些事记过，对方再提到会重新记一条；
- 清空不动好友档案，标签与记忆都保留。

## 工作群

群管理页（AI → 群组 → 点群）打开「工作群」后，每次总结会额外判断两件事：

- **当前任务**：群里有人负责、还在推进的事；只是讨论过的不算。
- **进度**：按这件事推进到的程度估一个 0~100 的整数。

结果显示在总览的群名后面：`群名 · 需求评审 60%`。

- 这一段没提到任务、也看不出新进展时，沿用上一轮记录；明确完成或换任务才改。
- 关掉「工作群」即清空任务；历史摘要保留每一轮当时的任务与进度。
- 进度是模型按聊天内容估的，不是精确值；只随每次总结更新，不单独请求。

### 工作汇报

工作群的摘要列表顶部有「汇报」文字和箭头：

1. 点「汇报」：把这个群到目前为止的摘要交给 AI，整理成一份项目汇报——做了什么、现在到哪了、还差什么。生成完自动展开。
2. 点箭头：切换已有汇报的显示，不重新请求。
3. 正文下方「复制」：把汇报复制到剪贴板，可直接粘到工作群或文档里。

- 按「给上级看」的口吻写：先给整体判断，再说做了什么、到哪了、还差什么。
- **快慢由它自己判断**：会看这批摘要覆盖了多久、任务推进了多少，再决定措辞——推进快就写驾轻就熟、配合顺畅、按节点甚至提前；平稳就写按计划推进、风险可控；偏慢就写清这一步为什么要慢下来（核对细节、打牢基础、避免返工），并列这段时间完成了什么。
- 读者不懂技术也能看懂：少讲实现细节，多讲阶段、结果和风险；术语用一句人话解释；看不出「为什么慢」时不硬解释，只陈述状态。
- 没有新摘要时再点「汇报」直接用上一次的结果，有新的总结后才重算。
- 最多参考最近 40 轮摘要、正文 300 字以内；没做完的仍写在「还没完成」里。
- 普通群（未开工作群）没有这两个按钮。

## 说明

- 每条带的是**记录时刻**，不是事件发生的时间。
- 每人最多 100 条、保留 180 天。
- 同一件事当天只记一次；第二天对方再提，会作为新的一条记录。
