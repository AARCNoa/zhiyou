# 朋友圈帮我评论

**AI · 朋友圈** · 开关在 `AI → 设置`（默认开） — 长按对方朋友圈的文字，让 AI 写三条不同风格的评论。

## 用法

1. 先填 AI 接口（`微信 → 我 → 设置 → 知友 → 主页 AI 卡片 → 配置`）。没配接口时菜单里不出现这一项。
2. 长按**对方**朋友圈的文字 →「帮我评论」。
3. 先出现一枚三点药丸，随后展开成卡片：顶部是对方名字和这条动态的预览。
4. 点一条复制，行尾显示「已复制」；回朋友圈长按文字粘贴。

它读这条动态的文字与图片（最多 3 张），结合对方的标签与近期事件，写三条风格不同的评论：
熟人打趣、真心回应、顺着细节聊。

## 素材范围

| 内容 | 怎么处理 |
| --- | --- |
| 文字 | 全部读入 |
| 图片 | 最多 3 张（压到 800px）；没有缓存时当场取一次，最多等 6 秒，仍拿不到就按文字写 |
| 视频 | 不解析画面；能拿到封面时随封面一起传 |
| 好友档案 | 有档案时带标签与最近 40 条事件标题，名字下方显示「记忆 N · 标签 M」 |

## 说明

- 三条评论风格不同，不会三条说同一句话。
- 卡片里可展开「思考过程」，看模型怎么判断这条动态；「深度思考」关着时不显示。
- 只复制，不自动发评论——发不发、发哪条由你决定。
- 关掉后菜单里不再出现这一项。
