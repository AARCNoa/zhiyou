# 跳过启动页面

**小程序** · 可开关 · 实验性 — 跳过小程序的启动画面，变相去广告。

小程序打开时会先显示一个「Loading 页」，不少小程序把它当开屏广告位。本功能 Hook
`AppBrandRuntime` 里展示该页面的无参方法，让它直接返回。

## 说明

- 启用后直接打开小程序即可，不需要重启微信；主进程与 `:appbrand` 进程都生效。
- 锚点按字符串 `Loading页展示` 定位，微信改文案后会失效，自检页会标为待适配。
- 只对返回 `void` 的方法置空，避免误伤同名但返回对象的方法（如 `getInstance`）。
- 跳过的只是启动画面，不改变小程序本身的其它广告逻辑。
