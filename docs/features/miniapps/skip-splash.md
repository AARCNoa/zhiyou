# 跳过启动页面

> 跳过小程序启动页面, 变相去广告 (实验性)

## 类别

小程序

## 类型

可开关

## 描述

小程序打开时会先显示一个「Loading 页」，很多小程序把它当开屏广告位。本功能 Hook
`AppBrandRuntime` 中负责展示该页面的无参方法，让它直接返回，从而跳过启动画面。

## 使用方法

启用后直接打开任意小程序即可，不需要重启微信。主进程与 `:appbrand` 进程都会生效
（小程序逻辑跑在 `:appbrand`）。

## 说明

- 锚点按字符串 `Loading页展示` 定位，微信改文案后会失效 —— 自检页会标为待适配；
- 只对返回 `void` 的方法置空，避免误伤同名但返回对象的方法（如 `getInstance`），
  否则会抛 `ClassCastException`；
- 跳过的是启动画面，不改变小程序本身的其它广告逻辑。
