# 模块设置说明

入口：`微信 → 我 → 设置 → 知友`（另有首页 `+` 菜单、模块 App）。界面为四个 Tab：
**主页 / AI / 日志 / 设置**，底部导航切换。

## 主页

自上而下三张卡，同一套模板（白底、1dp 描边、20dp 圆角、间距一致）：

| 卡片 | 内容 | 点击 |
|---|---|---|
| 模块已激活 | 勾号 + 自检摘要（已解析 N/M） | 右侧「自检」进模块自检页 |
| 统计 | 已启用 / 全部功能 / 分类 | 弹半屏清单；分类可再进二级直接开关 |
| 模块信息 | 激活框架 / 微信版本 / 模块版本 | — |

顶部品牌头右侧是搜索（放大镜）与三点菜单（帮助 / 关于）。搜索只在主页内过滤功能名与描述。

**半屏清单**：统计卡三格各开一份。「已启用」与「全部功能」直接列出条目；
「分类」先列 15 个分类及 `已启用 N/M`，点分类在**同一张半屏里**展开该分类的功能（可直接开关），
返回键先回分类列表、再收起半屏。

「密友功能」的二级清单末尾多一张**状态诊断**卡（总开关 → 功能列表 → 状态诊断）：
折叠时只有一行汇总（「全部正常」或「N 项异常」，有异常默认展开），展开后列出名单人数、
临时显示、三击标题、搜索口令、微信数据库、各类锚点与 DexKit 解析情况，末尾两个操作
「刷新会话列表」「复制诊断信息」。全部操作都在这张半屏内完成，不再跳独立页面。
只显示**设置页里看不到的只读状态**——总开关与各拦截开关本身就是上面的可开关行，不重复列。

## AI

页面分三段（顶部胶囊切换）：**好友 / 群组 / 设置**。

| 段 | 内容 |
|---|---|
| 好友 | A-Z 分组 + 右侧索引条；点卡片进七页管理弹窗（概览 · 聊天目标 · 回复风格 · 标签 · 记忆 · 审查建议 · 变动记录），长按删除档案 |
| 群组 | 群聊总结列表：头像、群名、频率、未读与上次状态；右上「添加群」多选添加，点卡片进管理页，长按删除 |
| 设置 | 双击提示音开关 + 音色（点一下试听并选中） |

接口配置不在 AI 页：主页「AI 已激活 / 未激活」卡右侧的**配置**进入（Base URL、Key、模型名、
深度思考、思考强度、输出上限、温度、识别图片）。debug 包在 AI 页顶部多一个「提示词」按钮，
渲染的是运行时同一批提示词函数。

微信首页标题栏还有一个**摘要图标**（搜索图标左边，带未读红点）：点开是群总结面板，
卡片进历史，打开即清零该群未读。面板与侧边栏开关、侧边栏实现方式都无关。

## 设置

六组，全部白卡 + 小标题：

| 分组 | 项 |
|---|---|
| 界面 | 主题模式；自定义颜色（开启后出现动态壁纸取色、种子颜色、调色板样式、颜色规格、同时对微信生效） |
| 微信主题 | 主题工坊（内置主题、全局壁纸、气泡、透明度、备份恢复） |
| 调试 | 详细日志、显示加载完成 Toast、清理消息 ID 前缀时允许非标准 ID |
| 兼容 | 禁用版本适配、重置适配信息、宿主热更新时重新适配 |
| 配置 | 导出 / 导入 / 清除（不可逆，有确认框） |
| 关于 | 开源许可（版本与框架信息在主页「模块信息」卡里） |

适配三项的用途：

- **禁用版本适配**：跳过 DexKit 重扫，未适配的功能直接不加载；微信版本变化时自动关闭；
- **重置适配信息**：清空 `dex_cache/`，下次启动重扫（功能异常时首选）；
- **宿主热更新时重新适配**：微信自身热更新后自动重置缓存（实验性，默认关闭）。

主题三项下拉（主题模式 / 调色板样式 / 颜色规格）与「选择日志文件」共用 `DropdownField`：
**列表紧贴该行下方弹出，无整屏遮罩**；长列表限高、内部滚动。

## 日志

- 右上角两个图标：**筛选**（运行日志 / 崩溃日志）与分享；三点菜单提供刷新、转到顶部、
  转到底部、清空。
- 顶部统计四格：错误 / 警告 / 信息 / 调试，点任意一格弹底部浮层列出该级别条目，
  可跳转到原文或复制。
- 「选择日志文件」可按日期切换；日志同时写入
  `/sdcard/Android/data/<宿主包名>/WCX/logs/`。

## 功能分类

15 个分类，分类行上的「已启用 N/M」按 `SwitchFeature.effectiveEnabled` 统计；
可点击功能排在分类清单里，名称旁有齿轮表示可进入详细配置。

| 分类 | 数 | 覆盖 |
|---|---:|---|
| 聊天 | 71 | 防撤回、自动回复、对话归拢、消息过滤、悬浮标题栏、Markdown |
| 系统与隐私 | 29 | 反检测、环境伪装、虚拟定位、步数、平板模式、DPI、API + MCP 服务 |
| 朋友圈 | 23 | 防撤回、自动点赞 / 转发、关键词屏蔽、广告拦截、批量删除 |
| 密友功能 | 19 | 隐藏联系人在会话 / 通讯录 / 搜索 / 朋友圈 / 通话等面的屏蔽（受总开关控制） |
| 界面美化 | 24 | 主题、侧边栏、气泡、导航栏、对话框模糊、头像圆角、彩虹文本、图片旋转 |
| 联系人与群组 | 16 | 隐藏联系人、单向删好友检测、自动同意、群成员实名 / 身份、自动备注、详情页增强 |
| 小程序 | 10 | 去广告、跳过启动页、Eruda、限制解除 |
| 调试 | 10 | 崩溃拦截、日志重定向、内存分析、复制调试信息 |
| 红包与支付 | 8 | 自动抢红包、金额统计、捡漏历史红包、指纹支付、自动收转账 |
| 批量操作 | 8 | 批量删好友 / 记录 / 标签 / 免打扰 / 隐藏对话、群发、导出 |
| 首页右上角菜单 | 7 | 自定义首页 `+` 菜单项 |
| 音视频通话 | 5 | 铃声屏蔽、画中画、通话中聊天限制、虚拟视频通话、临时通话 |
| 公众号 / 视频号 | 4 / 3 | 去广告、网页多开、旧版列表、媒体下载 |
| 个人资料 | 4 | 昵称、透明头像、签名限制、清空资料信息 |

> API（43 个）是内部服务，不建卡。
> 功能默认只挂一个分类，「隐藏联系人」同时出现在「联系人与群组」与「密友功能」
> （后者是该分类的总入口，属于刻意保留的双入口），所以各行相加比功能总数多 1。
