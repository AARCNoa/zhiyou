# 模块设置说明

入口：`微信 → 我 → 设置 → 知友`（另有首页 `+` 菜单、侧边栏、模块 App）。界面为四个 Tab：
**主页 / AI / 日志 / 设置**，底部导航切换。

## 主页

自上而下三张卡，同一套模板（白底、1dp 描边、20dp 圆角）：

| 卡片 | 内容 | 点击 |
|---|---|---|
| 模块已激活 | 勾号 + 自检摘要（已解析 N/M） | 右侧「自检」进模块自检页 |
| 统计 | 已启用 / 全部功能 / 分类 | 弹半屏清单；分类可再进二级直接开关 |
| 模块信息 | 激活框架 / 微信版本 / 模块版本 | 有新版时这一行会提示，见[应用内更新](features/system/app-update.md) |

顶部品牌头右侧是搜索（放大镜）与三点菜单（帮助 / 关于）。搜索只在主页内过滤功能名与描述。

**半屏清单**：统计卡三格各开一份。「已启用」与「全部功能」直接列出条目；「分类」先列 15 个分类及
`已启用 N/M`，点分类在**同一张半屏里**展开该分类的功能（可直接开关），返回键先回分类列表、再收起半屏。

「密友功能」的二级清单末尾多一张**状态诊断**卡（总开关 → 功能列表 → 状态诊断）：折叠时只有一行
汇总（「全部正常」或「N 项异常」，有异常默认展开），展开后列出名单人数、临时显示、三击标题、搜索口令、
微信数据库、各类锚点与 DexKit 解析情况，末尾两个操作「刷新会话列表」「复制诊断信息」。
只显示设置页里看不到的只读状态——总开关与各拦截开关本身就是上面的可开关行，不重复列。

## AI

页面分三段（顶部胶囊切换）：**好友 / 群组 / 设置**。

| 段 | 内容 |
|---|---|
| 好友 | A-Z 分组 + 右侧索引条；点卡片进七页管理弹窗（概览 · 聊天目标 · 标签 · 记忆 · 审查建议 · 变动记录 · 回复风格），长按删除档案 |
| 群组 | 群总结列表：头像、群名、频率、未读与上次状态；右上「添加群」多选添加，点卡片进管理页（自动总结、工作群、频率、立即总结、历史），长按删除 |
| 设置 | 回复延迟（默认 8 秒，可点数字原地改，范围 3~60）；朋友圈帮我评论开关；双击提示音开关 + 音色（点一下试听并选中） |

好友概览页的「功能」卡片里可以开关智能建议、自动回复、自动增量整理（含每天的执行时间）。

聊天页双击屏幕出「智能建议」（胶囊 → 卡片）；卡片打开时再次双击等于右上角 ↻（换一批）。
离开聊天页（含按返回回首页）会自动收起，加载中的胶囊一并作废。

接口配置不在 AI 页：主页「AI 已激活 / 未激活」卡右侧的**配置**进入（Base URL、Key、模型名、
深度思考、思考强度、输出上限、温度、识别图片）。debug 包在 AI 页顶部多一个「提示词」按钮，
渲染的是运行时同一批提示词函数。

首页标题栏搜索图标左边还有一个**便签图标**（带未读角标），点开是「总览」：今日总结、好友事件、
群摘要。只有至少一个群开启自动总结、或至少一位好友开启自动回复时才显示。
红点数 = 群未读 + 好友未读，点进某一项即清零该项。详见[总览](features/ai/overview.md)。

## 设置

七组，全部白卡 + 小标题：

| 分组 | 项 |
|---|---|
| 界面 | 主题模式；自定义颜色（开启后出现动态壁纸取色、种子颜色、调色板样式、颜色规格、同时对微信生效） |
| 微信主题 | 主题工坊（内置主题、主页四页与聊天背景壁纸、气泡、界面透明度、备份恢复；透明度只调控件底衬） |
| 调试 | 详细日志、显示加载完成 Toast、清理消息 ID 前缀时允许非标准 ID |
| 兼容 | 禁用版本适配、重置适配信息、宿主热更新时重新适配 |
| 配置 | 导出 / 导入 / 清除（不可逆，有确认框） |
| 更新 | 检查更新（副标题显示当前版本与检查结果），见[应用内更新](features/system/app-update.md) |
| 关于 | 项目地址、交流群、开源许可（版本与框架信息在主页「模块信息」卡里） |

适配三项的用途：

- **禁用版本适配**：跳过 DexKit 重扫，未适配的功能直接不加载；微信版本变化时自动关闭；
- **重置适配信息**：清空 `dex_cache/`，下次启动重扫（功能异常时首选）；
- **宿主热更新时重新适配**：微信自身热更新后自动重置缓存（实验性，默认关闭）。

主题三项下拉（主题模式 / 调色板样式 / 颜色规格）与「选择日志文件」共用同一套下拉：
**列表紧贴该行下方弹出，无整屏遮罩**；长列表限高、内部滚动。

## 日志

- 右上角两个图标：**筛选**（运行日志 / 崩溃日志）与分享；三点菜单提供刷新、转到顶部、转到底部、清空。
- 顶部统计四格：错误 / 警告 / 信息 / 调试，点任意一格弹底部浮层列出该级别条目，可跳转到原文或复制。
- 「选择日志文件」可按日期切换；日志同时写入 `/sdcard/Android/data/<宿主包名>/WCX/logs/`。

## 功能分类

15 个分类，分类行上的「已启用 N/M」按各功能的实际开关状态统计；
可点击功能排在分类清单里，名称旁有齿轮表示可进入详细配置。

| 分类 | 覆盖 |
|---|---|
| 聊天 | 防撤回、自动回复、对话归拢、消息过滤、悬浮标题栏、Markdown |
| 系统与隐私 | 反检测、环境伪装、虚拟定位、步数、平板模式、DPI |
| 朋友圈 | 防撤回、自动点赞 / 转发、关键词屏蔽、广告拦截、批量删除 |
| 密友功能 | 隐藏联系人在会话 / 通讯录 / 搜索 / 朋友圈 / 通话等面的屏蔽（受总开关控制） |
| 界面美化 | 主题、侧边栏、气泡、导航栏、对话框模糊、头像圆角、彩虹文本、图片旋转 |
| 联系人与群组 | 隐藏联系人、单向删好友检测、自动同意、群成员实名 / 身份、自动备注、详情页增强 |
| 小程序 | 去广告、跳过启动页、Eruda、限制解除 |
| 调试 | 崩溃拦截、日志重定向、内存分析、复制调试信息 |
| 红包与支付 | 自动抢红包、金额统计、捡漏历史红包、指纹支付、自动收转账 |
| 批量操作 | 批量删好友 / 记录 / 标签 / 免打扰 / 隐藏对话、群发、导出 |
| 首页右上角菜单 | 自定义首页 `+` 菜单项 |
| 音视频通话 | 铃声屏蔽、画中画、通话中聊天限制、虚拟视频通话、临时通话 |
| 公众号 / 视频号 | 去广告、网页多开、旧版列表、媒体下载 |
| 个人资料 | 昵称、透明头像、签名限制、清空资料信息 |

> 各类数量与内部服务清单见[功能索引](features/README.md)，内部服务不建卡、无开关。
> 「隐藏联系人」同时出现在「联系人与群组」与「密友功能」（后者是该分类的总入口），属于刻意保留的双入口。
