# 配置

## 入口

任选一种打开模块设置：

1. 微信 → 我 → 设置 →「知友」；
2. 微信首页 → 右上角 `+` 菜单 →「知友」；
3. 启用「界面美化 / 微信主页侧边栏」或「主屏幕添加 FAB」后，从侧边栏 / 浮动按钮进入；
4. 桌面「知友」App →「打开模块设置」（宿主包名为 `com.tencent.mm` 时可用）。

第 4 条的 App 只是启动器：顶部显示激活状态，并提供「修复模块加载 / 清除模块数据 /
隐藏桌面图标 / 设置宿主包名」。功能开关都在微信内。

## 功能与通用设置

- 功能开关按 15 个分类组织（主页「分类」半屏进入），可点击项名称旁带齿轮；
- 通用设置（主题、日志、适配、导入导出）在「设置」Tab。

逐项说明见 [模块设置说明](module-settings.md)。

## 数据目录

模块数据根目录：`/sdcard/Android/data/<宿主包名>/WCX/`

```none
WCX/
├── logs/        运行日志（wcx-YYYY-MM-DD.log）
├── crashes/     崩溃日志（需开启「调试 / 崩溃拦截」）
├── dex_cache/   DexKit 锚点缓存（自动生成，删掉会重扫）
├── assets/      自定义气泡（left_bubble.9.png / right_bubble.9.png）
└── stickers/    贴纸包（每个子目录一包）
```

导出与下载的图片、语音、文件存放在 `Download/zhiyou/`。

AI 数据不在上面这个目录，而在微信的私有目录里（同样卸载不丢）：

```none
/data/data/<宿主包名>/files/ai/
├── profiles/     好友档案（每个 wxid 一个 JSON）
├── index.json    好友索引（列表、自动回复开关）
├── overview.json 总览里的好友重要事件（含已读状态）
├── today.json    今日总结（当天一份，跨天失效）
└── groups/       群总结（每群一个 JSON + index.json 索引）
```

## 配置存储

配置写 MMKV：`/data/data/<宿主包名>/files/mmkv/wekit_prefs`（多开为
`/data/user/<用户 ID>/<宿主包名>/files/mmkv/`）。

- 卸载模块**不会**丢配置——文件在微信数据目录里；
- 需要重置时优先用「设置 → 配置 → 清除配置」，直接删文件会丢失全部设置；
- MMKV 由微信进程在启动时初始化，**模块 App 读不到**（独立进程、独立目录），所以微信里选的深色模式不会同步到桌面 App，后者固定跟随系统。
